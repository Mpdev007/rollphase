**Plain-language key**
- **Blocker:** not production-ready until fixed. **Major:** a real function is broken, fake or missing. **Minor:** a rough edge.
- **Fake green:** the screen says something worked when it didn't.
- **Service worker (SW):** `sw.js`, the script that caches the app so it opens offline.
- **OSM:** OpenStreetMap. **Nominatim**, **Photon** and **Overpass** are the free OSM search services the app asks for venues.
- **CDN / edge cache:** the copy servers GitHub Pages puts in front of the site.
- **PWA:** the installable-web-app form of the site. **Standalone:** the installed app running without a browser URL bar.
- **Hash route:** the part of the URL after `#` (for example `#/profile`) that tells the app which screen to open.
- **DPR:** device pixel ratio. The owner's S25 is DPR 4 (4 screen pixels per CSS pixel). DPR 1 is a normal-density screen, which is how you judge blur.
- **Origin:** the scheme plus host a web app runs under (here `https://mpdev007.github.io`). Browsers give storage, caches and permissions per origin, not per app.
- **CLS (layout shift):** how much visible content jumps after it first appears. Above 0.25 is "poor".
- **WCAG 2.2 AA:** the standard accessibility bar. **Screen reader** (TalkBack on Android) reads the page aloud from its accessibility tree.
- **Web Share API (`navigator.share`):** opens the phone's own share sheet.
- **CSP / SRI:** Content-Security-Policy (which scripts may run) and Subresource Integrity (refuse a CDN file that changed).
- **SSRF:** a server tricked into fetching internal addresses for an attacker. **EXIF:** photo metadata, which can include GPS.
- **Local Network Access (LNA) prompt:** Chrome's system prompt when a public site tries to reach this device (`127.0.0.1`).
- **Row-level security (RLS):** database rules that stop one user reading another user's private rows.
- **Web Push / VAPID:** the browser's standard way to deliver notifications; VAPID is the key pair that signs them.
- **Worker / OffscreenCanvas:** a background thread that can draw images, so recolouring icons doesn't freeze the screen.
- **Trim mask:** the grey image next to each pack icon that marks which pixels take the chosen hue.

## 0. What changed since 09-25

Pass 2 re-tested the same build as the owner's own phone would run it and found that the app is less finished than pass 1 scored. There are no new blockers, but there are **25 new majors**:
- **Sharing:** sharing is one buried text button, and there is no QR code.
- **About and privacy:** About is a developer sheet with no version, and there is no privacy policy.
- **Navigation:** the phone's Back button closes the app from any tab, and "‹ Gyms" on a shared venue leaves the app.
- **Layout and performance:** Home jumps about 306 px on every boot, landscape shows a desktop mock-up, and opening Gyms freezes for about half a second on a mid-range phone.
- **Accessibility:** pinch-zoom is locked, and venues, sheets and the welcome gate can't be used by keyboard or screen reader.
- **Location and origin:** blocking location doesn't stop the app from sending the last saved location, and the app shares its web origin with another app.
- **Icon packs:** the masks miss trim on the Home icon in three packs, and the Profile strap turns blue in Bright and Ice.
