# RollPhase beta — tester guide

## What this is

A **clickable mobile prototype** of RollPhase so friends can judge flow, clutter, multi-sport behavior, and personalization **before** native iOS/Android + Supabase.

| Real | Not real yet |
|------|----------------|
| UX structure, skins, multi-sport home | Live gym database |
| Mock partners / events / check-ins | Real accounts & chat |
| Logo upload + colors + Nix *API shape* | Production Nix on every phone |
| Beta disclaimer + feedback | App Store / Play billing |

## How to test (10 minutes)

1. Read the **disclaimer** → check the box → **Enter beta**
2. **Home** — try multi-sport profile vs guest demo
3. Tap a sport for “today’s focus”; tap again to clear (Explore)
4. **Gyms** / **Partners** / **Feed** with and without focus
5. **Profile** → add/remove sports; **I represent…** upload + colors + Analyze
6. Tap **Feedback** (top right) with anything confusing or great

## What we want from you

- Confusion points (“I didn’t know I could…”)
- Moments that feel high-end vs cheap
- Whether multi-sport feels free or locked
- Represent personalization: useful or overkill?
- Anything that felt “hardcoded” or fake

## Privacy

Preferences live in **your browser** only. Clear site data to wipe. Don’t upload secrets or logos you can’t use.
